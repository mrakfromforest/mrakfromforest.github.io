Privacy Policy

Last updated: November 23, 2026

What Media Tools is

Media Tools is a private desktop utility used by its owner to manage their own YouTube channels. It is not offered to the public.

YouTube API Services

Media Tools uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data accessed

With the channel owner's permission (Google OAuth), Media Tools accesses:

  • channel and video information, analytics and revenue reports;
  • comments on the channel's videos;
  • the ability to upload and edit videos, thumbnails and captions, and to reply to comments.

How data is used and stored

Data is used only to manage and analyze the owner's own channels. Access tokens and reports are stored locally on the owner's computer. No data is sold, shared with third parties, or used for advertising.

Deleting data and revoking access

Access can be revoked at any time at myaccount.google.com/permissions or via the Google security settings page. After access is revoked, locally stored tokens stop working and are deleted. Stored reports are deleted on request.
